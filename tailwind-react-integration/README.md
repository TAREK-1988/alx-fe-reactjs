# React JS with a CSS Framework — Tailwind + Vite

This project integrates Tailwind CSS into a React application using Vite and demonstrates:
- Tailwind setup via the Vite plugin
- Utility-first styling in React components
- Responsive design utilities
- Interactivity with hover effects and transitions
